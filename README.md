Самая частая доплата — не железо, а лицензии и период оплаты. Четыре пункта ниже стоит проверить до заказа любого Windows VPS, не только AVA.

### Windows Server включает две административные RDP-лицензии

В FAQ ОБИТ прямо сказано: в состав Windows Server входят две лицензии для административного подключения по RDP. Официальный FAQ RUVDS: «Все серверы оплачиваются за весь период от создания сервера до его удаления». Ресурсы зарезервированы под вас, поэтому остановка виртуалки не останавливает счётчик. У других провайдеров условие может отличаться, но проверять его нужно в договоре, а не в описании тарифа.

## Вопросы, которые задают перед оплатой

**Можно ли взять Windows 10 или 11?**
У провайдеров в аренду обычно только Windows Server 2019, 2022 и 2025. ОБИТ прямо пишет, что Windows 10 и 11 не выдаёт. Для RDP и 1С серверная редакция подходит лучше: она рассчитана на нескольких пользователей.

**Сколько человек могут одновременно работать по RDP?**
Две административные сессии входят в Windows Server. Для одновременной работы сотрудников нужны пользовательские CAL. Считайте по числу одновременных подключений, а не по числу созданных аккаунтов.

**Выключенный сервер оплачивается?**
У RUVDS — да, по официальному FAQ. У других провайдеров проверяйте договор: часть тоже резервирует ресурсы независимо от состояния виртуалки.

**Цена с НДС?**
У AVA цена в евро; налоги и курс зависят от способа оплаты. У российских провайдеров уточняйте, включён ли НДС. С 2026 года есть примеры повышения на 5% из-за НДС.

**Годовая оплата действительно дешевле?**
Иногда да, но сравнивайте полную сумму за 12 месяцев и цену продления. У RU VDS 1 448 ₽/мес действует только при годовой оплате.
